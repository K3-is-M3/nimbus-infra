# Kloud Infra Portfolio

A responsive, static portfolio website built with plain HTML, CSS, and JavaScript. No framework, package manager, or build step is required.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — layout, responsive styling, and visual design
- `app.js` — mobile navigation and dynamic footer year

## Run locally
Open `index.html` in a browser, or serve the directory with any static web server.

## Before publishing
- Replace the placeholder contact email (`hello@kloudinfra.dev`) with a real address.
- Replace project descriptions with verified implementation details as appropriate.
- Add real repository/demo URLs where available.
- The portfolio is a static site; its contact link opens the visitor's email client and does not submit to a backend.
